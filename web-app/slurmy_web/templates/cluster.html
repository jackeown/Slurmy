Active SLURM tasks

Running and pending tasks are both shown. Each Slurmy batch is one SLURM array task, executing its solver-problem pairs sequentially; one Slurmy job can have many tasks. Counts and rows represent SLURM queue entries, not complete Slurmy jobs. Non-Slurmy entries may be ordinary SLURM job allocations containing multiple process tasks. New Slurmy submissions publish job-wide solver-problem pair and batch counts in SLURM's queue metadata, visible across users. Older submissions show counts only when this account can read their private metadata. Core counts describe allocated physical cores, which can exceed the solver's own core limit. A dash means no allocation is available yet or its core allocation could not be determined.
